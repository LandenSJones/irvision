Write Commands (Control and Configuration)
Command Name	Hex Code	Description
NOP	0x00	No Operation (ignored)
SWRESET	0x01	Software Reset
SLPIN	0x10	Sleep Mode ON (Power Save)
SLPOUT	0x11	Sleep Mode OFF (Wake Up)
PTLON	0x12	Partial Display Mode ON
NORON	0x13	Normal Display Mode ON
INVOFF	0x20	Display Inversion OFF
INVON	0x21	Display Inversion ON
DISPOFF	0x28	Display OFF
DISPON	0x29	Display ON
CASET	0x2A	Set Column Address
RASET	0x2B	Set Row Address
RAMWR	0x2C	Write Data to RAM (GRAM)
RAMRD	0x2E	Read Data from RAM (GRAM)
PTLAR	0x30	Partial Area Definition
VSCRDEF	0x33	Vertical Scrolling Definition
TEOFF	0x34	Tearing Effect Line OFF
TEON	0x35	Tearing Effect Line ON
MADCTL	0x36	Memory Access Control (Rotation, Mirroring, RGB/BGR)
VSCRSADD	0x37	Vertical Scroll Start Address
IDMOFF	0x38	Idle Mode OFF
IDMON	0x39	Idle Mode ON
COLMOD	0x3A	Interface Pixel Format (Color Depth)
RAMCTRL	0xB0	RAM Control (Memory Configuration)
RGBCTRL	0xB1	RGB Control (Frame Rate Setting)
PORCTRL	0xB2	Porch Control (Front and Back Porch Timing)
FRCTRL1	0xB3	Frame Rate Control (Setting)
GCTRL	0xB7	Gate Control (Power Configuration)
VCOMS	0xBB	VCOMS Setting (Voltage Control)
LCMCTRL	0xC0	LCM Control (Display Refresh Control)
IDSET	0xC1	ID Code Setting (Manufacturer ID)
VDVVRHEN	0xC2	VDV and VRH Control Enable
VRHS	0xC3	VRH Set (Regulator Voltage Control)
VDVS	0xC4	VDV Set (Power Configuration)
VCMOFSET	0xC5	VCOM Offset Set (Contrast Adjustment)
PWCTRL1	0xD0	Power Control 1 (Regulator Settings)
PWCTRL2	0xD1	Power Control 2 (Power Configuration)
PVGAMCTRL	0xE0	Positive Voltage Gamma Control
NVGAMCTRL	0xE1	Negative Voltage Gamma Control
🔹 2. Read Commands (Query Display Information)
Command Name	Hex Code	Description	Response Size
RDID1	0xDA	Read ID1 (Manufacturer ID)	1 byte
RDID2	0xDB	Read ID2 (LCD Module ID)	1 byte
RDID3	0xDC	Read ID3 (Driver Version)	1 byte
RDID	0x04	Read Display ID (Alternative ID Read)	3 bytes
RDDST	0x09	Read Display Status (ON/OFF, etc.)	4 bytes
RDDPM	0x0A	Read Display Power Mode	1 byte
RDDMADCTL	0x0B	Read Display MADCTL Settings	1 byte
RDDCOLMOD	0x0C	Read Display Color Mode	1 byte
RDDIM	0x0D	Read Display Image Mode	1 byte
RDDSM	0x0E	Read Display Signal Mode	1 byte
RDDSDR	0x0F	Read Self-Diagnostic Result	1 byte
GTSL	0x45	Get Scanline (Current Row Being Drawn)	2 bytes
